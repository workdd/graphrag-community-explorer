# Code of Conduct

## The short version

Be decent to the people you are talking to. Argue about the code, not about the person writing it.

## What is expected

- Assume the other person is trying to make the project better, and say what you mean plainly.
- Accept that a review is about the change, and give reviews that are about the change.
- English is not everyone's first language here, and neither is Korean. Read past the phrasing to
  the point being made.
- When you are wrong, say so and move on. Nobody is keeping score.

## What is not acceptable

Harassment, insults, or demeaning comments about anyone. Sexual attention or imagery. Publishing
someone's private information. Sustained disruption of an issue or a pull request. This applies in
issues, pull requests, discussions, commit messages and code review, and it applies whether or not
the person it is aimed at is present.

## If something goes wrong

Report it to the maintainer through a
[private security advisory](https://github.com/workdd/graphrag-community-explorer/security/advisories/new),
which is the private channel this repository has. Say what happened and where; a link is enough.

Reports are read by the maintainer and are not shared further. What follows depends on what
happened: a note asking someone to stop, an edited or deleted comment, or a block from the
repository. You will be told what was done.

The maintainer is held to this document too. If the problem is the maintainer's own behaviour, say
so in the report; there is no separate process, only the same one applied honestly.

## Scope

This applies in every space this project uses, and when someone is representing the project
elsewhere.

This document follows the intent of the [Contributor Covenant](https://www.contributor-covenant.org)
without copying its text; where it is silent, read the Covenant.
